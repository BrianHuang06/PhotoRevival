# 数据集质量分析与建设方案

## 1. 当前训练数据

当前统一训练入口默认使用：

```text
data/datasets/archive/03_Synthetic_Dataset/
├── Train_GT_Clean/          146 张目标图
└── Train_Input_Degraded/    146 张退化输入
```

检查结果：

| 项目 | 结果 | 判断 |
|---|---:|---|
| 配对数量 | 146 对 | 规模过小 |
| 可正常解码 | 146/146 | 合格 |
| 尺寸完全对应 | 146/146 | 合格 |
| 独立目标图 | 144 张 | 有 2 组完全重复图 |
| 分辨率种类 | 137 种 | 尺寸非常不统一 |
| 目标图中短边小于 256 | 43 张（29.5%） | 不适合直接训练 512 分辨率 |
| 目标图中短边小于 512 | 92 张（63.0%） | 多数样本训练时会被放大 |
| 退化 PSNR 中位数 | 19.59 dB | 退化强度中等 |
| 掩码覆盖率中位数 | 0.57% | 严重偏小 |
| 掩码覆盖率低于 1% | 105/146 | 严重偏小 |
| 空掩码 | 1 张 | 应剔除或重做 |
| 独立评估样本 | 6 张 | 无法可靠判断泛化能力 |
| 来源与授权元数据 | 0 条 | 无法追溯，不适合公开发布 |

### 优点

1. 输入和目标逐文件对应，尺寸一致，没有损坏文件。
2. 同时包含黑白、褐色和少量彩色照片，人物、合影和场景都有覆盖。
3. 输入与目标空间对齐，不需要额外配准即可训练。
4. 当前退化强度不是极端值，适合用来验证训练流程是否能运行。

### 主要问题

1. **样本量不足。** 146 对数据只适合流程验证或小规模消融，不足以支撑 SDXL LoRA 学到稳定、通用的老照片修复能力。
2. **目标图并不完全干净。** 抽样中仍有模糊、噪声、旧相纸边框、偏色和水印。模型会把这些内容当作正确答案。
3. **退化类型单一。** 当前输入主要表现为高频彩色噪声和细划痕，真实老照片常见的褪色、霉斑、折痕、撕裂、缺损、扫描光照不均和压缩退化覆盖不足。
4. **掩码与任务不匹配。** 掩码只覆盖极少量划痕，但输入还存在全局噪声和偏色。使用这些掩码训练 inpainting LoRA，模型会倾向于保持原图，难以学习全局修复。
5. **分辨率不足。** 92 张目标图短边不足 512，其中 43 张不足 256；放大训练会把压缩和模糊一并放大。
6. **缺少数据来源。** 目录中没有 URL、作者、授权、采集日期或原始文件哈希；抽样还出现可见图库水印，存在数据合规和论文复现风险。
7. **评估集过小。** 当前仅取 6 张合成图评估，而且与训练集来自同一生成方式，指标容易乐观。

综合评价：**5/10（流程验证可用，正式训练不足）**。当前最优先的问题依次是掩码、目标图质量、样本规模和真实测试集。

## 2. 下一版数据集目标

建议把数据分成三层，不要把所有图片混在一起：

| 数据层 | 建议规模 | 用途 |
|---|---:|---|
| 合成配对训练集 | 3,000-10,000 张干净原图，每张动态生成 2-4 个版本 | 主训练 |
| 真实损坏训练/验证集 | 300-1,000 张 | 调整真实域表现、检查掩码 |
| 独立真实测试集 | 100-300 张 | 最终评价，训练过程不得使用 |

第一阶段不必一次做到一万张。建议先完成 **1,000 张合格干净原图 + 3,000 个退化版本 + 150 张真实测试图**，验证新数据流水线后再扩充。

## 3. 推荐获取渠道

### 历史照片与真实损坏图

1. **Library of Congress（美国国会图书馆）**  
   提供照片目录和 JSON API，部分馆藏明确为公共领域。必须按具体馆藏的 Rights and Access 页面过滤，而不是默认所有图片都可用。  
   API：https://www.loc.gov/pictures/api  
   公共领域示例：https://www.loc.gov/collections/daguerreotypes/about-this-collection/rights-and-access/

2. **Smithsonian Open Access**  
   带 CC0 标记的素材可以下载、修改和分享，并提供公开 API。适合获取高分辨率历史扫描件和完整元数据。  
   https://www.si.edu/openaccess

3. **Europeana**  
   聚合欧洲博物馆、档案馆和图书馆资料，提供 API。下载时只保留 rights 字段明确允许当前用途的项目。  
   https://pro.europeana.eu/discover-the-data/apis

4. **Wikimedia Commons**  
   可优先筛选 Public Domain、CC0 或清晰可追溯的 CC BY 图片。每个文件授权不同，必须保存文件页 URL、作者和许可证。  
   https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia

5. **Flickr Commons**  
   收录大量文化机构历史照片，但“No known copyright restrictions”不是版权担保，使用前仍需检查贡献机构的权利声明。  
   https://commons.flickr.org/

6. **自有或合作采集（后续阶段）**  
   线下馆藏、家庭相册和现场扫描暂不纳入当前数据建设。本阶段先把官方 API、开放馆藏爬虫、License 白名单过滤和线上数据清洗跑稳定，后续确有需要时再单独制定线下授权与采集方案。

### 高质量干净图

1. **DIV2K**：800 张高分辨率图，适合补充通用场景和建立退化流水线。  
   https://data.vision.ee.ethz.ch/cvl/DIV2K/
2. **Smithsonian/Rijksmuseum 的 CC0 或 Public Domain 高分辨率素材**：适合历史人物、艺术品和扫描质感，但要控制绘画与照片比例。  
   https://data.rijksmuseum.nl/about/
3. **自行扫描保存良好的照片（后续阶段）**：当前暂不执行；未来启动时再制定扫描设备、分辨率和母版保存规范。

不建议使用搜索引擎图片、Pinterest、百度图片、来源不明的网盘数据或带 Shutterstock 等水印的素材。微软 Bringing Old Photos Back to Life 项目也明确没有公开其带标签的划痕数据集，因此不能把其模型预测掩码当作人工真值。

## 4. 数据预处理流水线

### 4.1 入库与追溯

每张原图建立一条 manifest 记录：

```json
{
  "id": "source_000001",
  "source_url": "...",
  "provider": "Library of Congress",
  "license": "Public Domain",
  "author": "...",
  "original_sha256": "...",
  "downloaded_at": "YYYY-MM-DD",
  "content_tags": ["portrait", "black_and_white"],
  "split": "train"
}
```

原始文件只读保存，后续所有裁剪、颜色转换和退化都生成新文件，不能覆盖母版。

### 4.2 自动质量筛选

1. 解码检查和 SHA-256 完全去重。
2. 使用感知哈希查找裁剪、缩放和轻微调色后的近似重复图。
3. 目标图短边建议至少 768，最低不得低于 512。
4. 删除水印、字幕、拼图、严重 JPEG 块、错误旋转和大面积纯色边框。
5. 统一 EXIF 方向并转换为 sRGB；保留黑白照片为 RGB 三通道，但不要强制上色。
6. 人脸过小、主体不可辨认的图片单独归为场景数据，不混入人脸增强子集。

### 4.3 先划分，再合成

以原始图片 ID 为单位划分 `train/validation/test = 80/10/10`，之后才生成退化版本。同一原图的所有裁剪和退化版本必须处于同一划分，防止数据泄漏。

真实测试集按来源机构、年代或相册分组划分，避免同一相册的近邻照片同时出现在训练集和测试集。

### 4.4 合成退化

建议把退化拆成可记录参数的图层：

- **全局退化**：褪色、色偏、对比度下降、gamma、暗角、曝光不均、纸张泛黄。
- **局部损坏**：划痕、裂纹、折痕、霉斑、灰尘、污渍、撕裂、乳剂缺失和边缘破损。
- **成像退化**：散焦/运动模糊、胶片颗粒、Gaussian/Poisson 噪声、下采样、扫描噪声和 JPEG 压缩。

不要固定三套模板。每次训练根据随机种子动态组合退化，并把参数写入 manifest。Real-ESRGAN 的官方训练方案支持只使用高质量原图、在线生成退化，也支持真实配对数据，可作为成像退化设计参考：  
https://github.com/xinntao/Real-ESRGAN/blob/master/docs/Training.md

局部掩码必须直接来自划痕/裂纹/缺损图层的 alpha mask，而不是再用检测器猜测。全局褪色、噪声和模糊不应使用极小的 inpainting mask；应采用全图修复阶段或全图 mask。

### 4.5 内容与退化平衡

建议记录并控制以下比例：

- 单人肖像约 35%，多人/家庭照约 20%。
- 室内外生活场景约 25%，建筑/街景约 15%，文档或特殊类型不超过 5%。
- 黑白、褐色和彩色照片都要覆盖。
- 轻度、中度、重度退化约为 30%/50%/20%。
- 每种主要损坏类型至少有数百个样本，避免模型只认识细划痕。

## 5. 验收门槛

开始正式训练前，至少满足：

1. 损坏文件为 0，配对和尺寸错误为 0。
2. 完全重复为 0，跨划分近似重复为 0。
3. 所有样本具备来源和授权记录。
4. 目标图短边至少 512，90% 以上达到 768。
5. 水印和可见版权标识为 0。
6. 空掩码为 0；局部损坏掩码覆盖率建议主要位于 1%-35%。
7. 验证集不少于 100 张，最终真实测试集不少于 100 张。
8. 每批数据自动生成抽样拼图，由人工检查输入、目标、掩码和元数据。

当前可复用检查工具：

```powershell
.\.venv\Scripts\python.exe -m scripts.diagnostics.audit_dataset
```

报告会生成到 `artifacts/reports/dataset_audit/`。

## 6. 公共领域照片下载器

项目提供了美国国会图书馆公共领域历史照片下载器。它会保存原图和逐图片元数据，执行尺寸过滤、权利检查、解码检查与 SHA-256 去重，并支持在已有 manifest 上继续下载。

```powershell
.\.venv\Scripts\python.exe -m scripts.data.download_loc_dataset --limit 50 --min-short-side 768
```

输出目录：

```text
data/raw/library_of_congress/daguerreotypes/
├── images/          原始图片，不应覆盖修改
├── manifest.jsonl   已接受图片及来源、授权、哈希、尺寸
└── rejected.jsonl   因尺寸、权利或下载问题被跳过的记录
```

继续增加 200 张：

```powershell
.\.venv\Scripts\python.exe -m scripts.data.download_loc_dataset --limit 200 --min-short-side 768
```
